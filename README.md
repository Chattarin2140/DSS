# Supply Chain DSS

ระบบสนับสนุนการตัดสินใจ (Decision Support System) ด้านห่วงโซ่อุปทาน จากข้อมูล `supply_chain_data.csv` (100 SKU)

## วิธีใช้

เปิด `web/index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งหรือรันเซิร์ฟเวอร์

ถ้าแก้ไขไฟล์ CSV ต้นฉบับ ให้สร้างข้อมูลใหม่ด้วย:

```
python clean.py
```

(ใช้แค่ Python standard library ไม่ต้องลง package เพิ่ม)

## หน้าในระบบ

| หน้า | การตัดสินใจที่ช่วย |
|---|---|
| ภาพรวม | KPI และข้อเสนอแนะสรุปจากทุกโมเดล |
| สินค้าและยอดขาย | รายได้ตามประเภท ราคา vs ยอดขาย กลุ่มลูกค้า |
| ประเมินซัพพลายเออร์ | จัดอันดับแบบ MCDM (SAW / TOPSIS) ปรับน้ำหนักได้ พร้อมทดสอบความไว |
| สต็อกสินค้า | จุดสั่งซื้อ (ROP) ปริมาณที่ควรสั่ง และดาวน์โหลดใบสั่งซื้อ CSV |
| การขนส่ง | เปรียบเทียบรูปแบบขนส่ง ผู้ให้บริการ และเส้นทาง |
| ข้อมูลและการคลีน | ขั้นตอนการคลีน โปรไฟล์คอลัมน์ และตารางข้อมูล |

## โครงสร้าง

```
archive (1)/supply_chain_data.csv   ข้อมูลต้นฉบับ
clean.py                            คลีนข้อมูล -> web/data.js, web/supply_chain_clean.csv
web/index.html                      หน้าเว็บ
web/assets/                         style.css, charts.js (กราฟ SVG), app.js (โมเดลและหน้าจอ)
```

## สมมติฐานที่ควรทราบ

- ข้อมูลไม่ระบุช่วงเวลาของยอดขาย หน้าสต็อกจึงให้ผู้ใช้กำหนดเอง (ค่าเริ่มต้น 180 วัน)
- รายได้ในข้อมูลไม่เท่ากับ ราคา × จำนวนที่ขาย จึงใช้คอลัมน์รายได้ตามต้นฉบับ
